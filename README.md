## 🔹 Proyectos Destacados

<details open>
<summary><b>🛍️ StreetWear — Backend REST API</b></summary>
<br/>

Aplicación web de comercio electrónico (e-commerce) enfocada en la venta de ropa urbana. Cuenta con un backend desarrollado en Spring Boot, autenticación y autorización mediante OAuth2 Resource Server y JWT, control de acceso basado en roles (`USER` y `ADMIN`), persistencia con MySQL y un frontend desarrollado con HTML5 y CSS3.

| Aspecto | Detalle |
|---|---|
| **Stack Backend** | Java · Spring Boot · Spring Security · OAuth2 · JWT · JPA/Hibernate · MySQL · HTML5 · CSS3 |
| **Seguridad** | OAuth2 Resource Server, JWT y control de acceso basado en roles (`USER`, `ADMIN`) |
| **Persistencia** | JPA/Hibernate sobre MySQL |
| **Documentación** | Swagger/OpenAPI |
| **Repositorio** | [StreetWear](https://github.com/NlCOl4S/StreetWear) |

</details>

<details>
<summary><b>⚽ Football League API — Backend REST API</b></summary>
<br/>

API REST para la gestión de una liga de fútbol. Desarrollada con Spring Boot, Spring Security (JWT), persistencia con MySQL mediante JPA/Hibernate, manejo global de excepciones y documentación interactiva con Swagger UI.

| Aspecto | Detalle |
|---|---|
| **Stack Backend** | Java · Spring Boot · Spring Security · JWT · JPA/Hibernate · MySQL |
| **Arquitectura** | API REST estructurada por capas con DTOs y mapeo manual |
| **Seguridad** | Autenticación basada en JWT |
| **Persistencia** | JPA/Hibernate sobre MySQL |
| **Documentación** | Swagger UI |
| **Repositorio** | [Football League](https://github.com/NlCOl4S/FootballLeague) |
